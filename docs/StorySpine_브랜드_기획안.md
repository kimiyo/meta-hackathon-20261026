# StorySpine 브랜드 기획안

작성일: 2026-10-30 · 버전: 1.0

브랜드명은 **StorySpine**으로 확정한다. 이 문서는 브랜드 전략과 표현 방향을 제안하며, 제품 기능의 구현 명세를 대체하지 않는다. 기존 코드와 화면의 이름 변경은 별도 적용 작업이다.

## 1. 브랜드의 중심

**이야기의 뼈대를 세우고, 완결까지 함께한다.**

StorySpine은 작가가 AI와 함께 소설을 기획하고, 집필하고, 설정의 일관성을 검토하는 창작 스튜디오다. 특히 회차가 쌓일수록 관리하기 어려워지는 인물·세계관·사건의 연결을 돕는다.

브랜드의 중심은 대량 생성이나 자동 출판이 아니라 **작가의 의도를 유지하면서 긴 이야기를 이어 가는 경험**이다. AI는 초안과 검토를 지원하고, 작가는 작품의 방향과 변경 내용을 결정한다.

| 항목 | 정의 |
|---|---|
| 브랜드명 | StorySpine |
| 한글 표기 | 스토리스파인 |
| 제품 분류 | AI 소설 창작 스튜디오 / AI Novel Studio |
| 핵심 사용자 | 장편 웹소설을 기획하거나 연재하는 개인 작가 |
| 핵심 문제 | 회차가 늘면서 흩어지는 설정, 흔들리는 구조, 반복되는 검토 부담 |
| 핵심 가치 | 이야기 구조, 설정의 연결, 작가의 결정권 |
| 브랜드 성격 | 차분한 창작 파트너, 꼼꼼한 편집자 |

## 2. 이름과 브랜드 스토리

**Story + Spine. 이야기와 등뼈.**

Spine은 몸을 지탱하는 등뼈이면서 책의 책등을 뜻한다. 이 두 의미를 연결해, 이야기의 내부 구조를 지탱하고 한 권의 작품으로 이어 가는 창작 공간을 표현한다.

> 한 화를 쓰는 일과 긴 이야기를 완성하는 일 사이에는 많은 연결이 필요합니다. 인물은 이전의 선택을 이어 가야 하고, 세계의 규칙은 다음 사건에서도 설득력을 가져야 합니다. StorySpine은 그 연결을 작가와 함께 살핍니다. 아이디어에 뼈대를 세우고, 설정을 정리하고, 다음 화로 이어 가도록 돕습니다.

브랜드를 설명할 때는 해부학적 이미지보다 **책등, 목차, 이어지는 회차**를 먼저 사용한다. 이름의 의미는 소개와 발표에서 설명하되, 일상적인 화면에서는 창작에 필요한 행동을 직접 안내한다.

## 3. 사용자와 사용 순간

| 사용자 | 필요한 순간 | 전달할 메시지 |
|---|---|---|
| 첫 장편을 준비하는 작가 | 소재는 있지만 작품 구조를 잡기 어려울 때 | 아이디어를 이야기의 뼈대로 |
| 연재 중인 작가 | 다음 화를 쓰기 전 앞선 설정을 확인할 때 | 앞선 이야기를 살펴보고 다음 화로 |
| 여러 인물과 세계관을 다루는 작가 | 인물 상태와 사건의 연결을 검토할 때 | 흩어진 설정을 작품 안에서 연결 |

초기 커뮤니케이션은 장편 웹소설 작가에 집중한다. 시나리오, 게임 서사, 협업 출판까지의 확장은 브랜드가 수용할 수 있지만, 해커톤 소개에서 모두 지원하는 것처럼 표현하지 않는다.

## 4. 포지셔닝과 가치 제안

### 포지셔닝 문장

장편 웹소설을 쓰는 작가를 위해, StorySpine은 **기획·집필·설정 검토를 하나의 흐름으로 연결하는 AI 소설 창작 스튜디오**다. 작가는 이야기의 방향을 정하고, AI는 구조화와 초안 작성, 일관성 검토를 지원한다.

### 세 가지 메시지

| 가치 | 사용자에게 하는 약속 | 제품에서 보여 줄 근거 |
|---|---|---|
| 구조를 세운다 | 막연한 아이디어를 집필 가능한 계획으로 발전시킨다 | 작품과 회차의 설계, 줄거리 구체화 |
| 연결을 살핀다 | 앞선 설정과 현재 원고를 함께 검토하도록 돕는다 | 설정 조회, 검증 결과, 변경 이력 |
| 작가가 결정한다 | AI의 제안을 검토하고 작품에 반영할 내용을 고른다 | 제안 적용, 원고 검토, 승인 흐름 |

위 근거는 구현 및 시연 확인 대상이다. 발표에는 실제 동작을 확인한 기능만 포함한다. 복선 자동 회수, 완벽한 기억, 오류 없는 장편 완성 등 검증되지 않은 성능을 약속하지 않는다.

## 5. 슬로건과 소개 문구

### 대표 슬로건

**이야기의 뼈대를 세우고, 완결까지 함께.**

**Give your story a spine.**

한국어는 창작 여정과 동행을, 영어는 이름의 의미와 기억하기 쉬운 표현을 담당한다. 두 문장은 직역 관계일 필요가 없다.

### 기능 설명

- 한국어: **기획부터 집필·설정 검토까지, AI 소설 창작 스튜디오.**
- 영어: **An AI novel studio for planning, drafting, and continuity review.**

### 짧은 소개

> StorySpine은 아이디어를 작품 구조로 발전시키고, 회차별 집필과 설정 검토를 연결하는 AI 소설 창작 스튜디오입니다. AI와 함께 이야기를 구체화하고, 작가의 판단으로 다음 화를 완성하세요.

### 해커톤 출품용 영문 소개

> StorySpine is an AI novel studio that helps writers plan, draft, and review long-form fiction. Using Meta’s Muse Spark through the Meta Model API, it connects story planning with episode drafting and continuity checks, while keeping the writer in control of what becomes part of the story.

기술명은 실제 사용 구성에 맞춰 제출 직전에 확인한다. 대표 슬로건에는 공급자 이름을 넣지 않고 기술 설명에 명시한다.

## 6. 말투와 용어

문장은 짧고 구체적으로 쓴다. AI의 판단과 작품의 확정 사실을 구분한다. 검토가 필요한 이유와 다음 행동을 함께 안내하며, 창작에 관한 최종 판단은 작가에게 남긴다.

| 상황 | 권장 문구 |
|---|---|
| 처음 시작 | 어떤 이야기를 시작할까요? |
| 작품이 없는 화면 | 첫 아이디어에 이야기의 뼈대를 세워 보세요. |
| 기획 시작 | 작품의 방향과 전체 흐름을 함께 정리해 보세요. |
| 집필 시작 | 이번 화에서 달라질 것은 무엇인가요? |
| 설정 충돌 가능성 | 앞선 설정과 다른 부분이 있습니다. 근거를 확인해 주세요. |
| 근거가 충분하지 않을 때 | 현재 자료만으로는 판단하기 어렵습니다. |
| 변경 제안 | 이 변경을 적용하면 다음 전개도 검토해야 합니다. |
| 원고 승인 | 검토한 원고와 설정 변경을 확정할까요? |
| 처리 실패 | 작업을 마치지 못했습니다. 다시 시도해 주세요. |

제품 용어는 ‘작품 / 구조 / 설정 / 회차 / 원고 / 검토 / 승인’을 중심으로 통일한다. 내부 구현 용어인 엔티티·커밋·상태머신은 일반 작가 화면에서 사용자 행동에 맞는 말로 바꾼다. 실제 저장과 승인 동작의 차이가 있는 곳에서는 그 차이를 명확히 설명한다.

피할 표현: ‘베스트셀러 보장’, ‘설정 오류 0%’, ‘모든 것을 완벽히 기억’, ‘작가 없이 완성’. 기대 효과를 실제 성능처럼 단정하지 않는다.

## 7. 시각 정체성

### 디자인 콘셉트: 오래 머물 수 있는 작가의 서재

아이보리 종이, 짙은 잉크, 깊은 녹색을 중심으로 구성한다. 기존 기획의 책장과 여백 중심 방향을 이어 가며, 장시간 원고를 읽고 다듬는 작업에 맞춘다.

| 역할 | 색상 | 적용 |
|---|---|---|
| Paper | `#F7F4EC` | 기본 배경 |
| Surface | `#FFFFFF` | 편집 영역, 카드, 대화 영역 |
| Ink | `#202C29` | 본문과 주요 제목 |
| Forest | `#214E40` | 주요 버튼, 선택 상태, 브랜드 강조 |
| Muted | `#5D6C65` | 보조 설명 |
| Line | `#DCDDD4` | 구분선과 테두리 |
| Brass | `#A77B3E` | 작은 장식과 보조 강조 |

Brass는 작은 본문 글자에 사용하지 않는다. 실제 UI에서 텍스트 대비와 포커스 표시를 검증한다. 검토·실패·완료는 색상과 함께 텍스트 또는 아이콘으로 구분한다.

### 타이포그래피

- 제품 UI: 한글과 영문이 자연스럽게 이어지는 가독성 높은 산세리프 계열.
- 브랜드 제목: 책의 인상을 주는 세리프 계열을 제한적으로 사용.
- 원고 영역: 충분한 줄간격과 읽기 편한 줄 길이를 우선하고, 본문 글꼴은 작가의 읽기 환경을 고려한다.
- 구체적인 서체는 한글 지원과 라이선스를 확인한 뒤 선정한다.

### 로고 방향

**책등과 연결된 회차를 결합한 심벌 + StorySpine 워드마크.**

하나의 세로 축에 짧은 가로 요소가 연결되는 간결한 형태를 제안한다. 책등의 구획과 이야기 구조를 함께 연상시키되, 의료용 척추 그림처럼 보이지 않도록 추상화한다. 작은 크기와 단색에서도 형태가 유지되어야 한다.

워드마크는 항상 `StorySpine`으로 쓴다. `Storyspine`, `Story Spine`, `StorySpine AI Studio` 등으로 표기를 늘리지 않는다. 제품 분류가 필요하면 별도 보조 문구 `AI Novel Studio`를 배치한다.

로고의 완성 도안과 사용 규격은 후속 제작물이다. 이 문서는 시각 방향을 정의한다.

## 8. 앱 화면에 적용하는 방식

| 접점 | 브랜드 적용안 |
|---|---|
| 브라우저 제목 | `StorySpine` 또는 `{작품명} · StorySpine` |
| 메인 로고 | `StorySpine` + 작은 보조 문구 `AI Novel Studio` |
| 메인 헤드라인 | 이야기의 뼈대를 세우고, 완결까지 함께. |
| 메인 설명 | 아이디어를 설계하고, AI와 집필하고, 앞선 설정과의 연결을 검토하세요. |
| 주요 버튼 | 새 소설 시작하기 |
| 기존 작품 버튼 | 이어 쓰기 |
| 아이디어 단계 | 이야기의 씨앗 |
| 설계 단계 | 이야기의 뼈대 |
| 집필 단계 | 다음 화 쓰기 |
| 검토 단계 | 연결 살펴보기 |

단계 이름의 감성 문구는 안내 제목에 활용한다. 실제 내비게이션은 ‘아이디어 / 소설 설계 / 집필 / 작가 검토’처럼 기능이 명확한 이름을 우선해 탐색을 쉽게 한다.

기술 제공자 표시는 소개 또는 기술 정보에서 제공한다. Meta의 로고나 공식 제품과 비슷한 워드마크를 브랜드 심벌로 사용하지 않는다.

## 9. 해커톤 발표 전략

### 한 문장 피치

**StorySpine은 작가가 긴 이야기를 설계하고, 쓰고, 앞선 설정과의 연결을 검토하도록 돕는 AI 소설 창작 스튜디오입니다.**

### 약 30초 영문 피치

> Writing one chapter is only the beginning. A long-running novel needs characters, world rules, and events to stay connected across episodes. StorySpine gives writers a shared workspace for planning, drafting, and continuity review. We use Meta’s Muse Spark to help structure ideas, draft episodes, and flag possible inconsistencies. Writers review the suggestions and decide what becomes part of their story. Give your story a spine.

### 시연의 중심 장면

1. 작가의 짧은 아이디어를 작품과 회차의 설계로 발전시킨다.
2. 설계와 관련 설정을 바탕으로 한 회차의 원고를 만든다.
3. 앞서 정한 설정과 충돌하는 내용을 넣고, 검토 결과와 근거를 보여 준다.
4. 작가가 수정 내용을 검토·승인하고 다음 회차로 이어 간다.

실제로 재현 가능한 시나리오를 준비한다. 검토 결과가 예시 데이터라면 예시임을 명시하고, 실시간 실행과 사전 준비 결과를 구분한다. ‘기억한다’는 표현은 저장된 정보와 조회·검토 동작을 직접 보여 주면서 설명한다.

첫 화면은 이름과 가치 제안, 본 시연은 연결 검토, 마지막 화면은 작가의 결정권으로 구성한다. 기술 설명에서는 Meta 모델이 수행하는 생성·해석·판정과 프로그램이 수행하는 저장·승인 관리를 구분한다.

## 11. 적용 순서와 완료 기준

| 순서 | 작업 | 완료 기준 |
|---|---|---|
| 1 | 브랜드명과 메시지 통일 | 대표 이름, 슬로건, 한 줄 소개가 출품 자료에서 일치 |
| 2 | 워드마크와 심벌 제작 | 단색·축소 버전과 앱 아이콘에서 식별 가능 |
| 3 | 제품 표기 변경 | 앱 제목, 헤더, 푸터, 빈 화면, 메타 정보의 표기를 점검 |
| 4 | 문서와 발표 갱신 | README, 제출 설명, 발표 표지, 데모 영상에서 이름 통일 |
| 5 | 데모 검증 | 소개 문구의 핵심 기능을 실제 시연으로 확인 |

기존 개발 문서의 과거 명칭은 필요한 경우 ‘구 Muse Novel Studio’로 연결해 이력을 남긴다. 모델 ID, API 식별자, DB 경로 등은 브랜드명 치환 대상으로 취급하지 않는다.

## 12. 확정 사항과 후속 작업

**확정:** 서비스명 StorySpine.

**이 기획안의 권고:** 대표 슬로건 ‘이야기의 뼈대를 세우고, 완결까지 함께.’, 영문 슬로건 ‘Give your story a spine.’, 서재를 연상시키는 아이보리·녹색 시각 체계.

**후속 작업:** 로고 제작, 실제 화면 적용, 제출 자료 갱신. StorySpine의 상표·도메인·서비스명 중복 여부는 이 문서에서 조사하지 않았으며, 이름의 사용 가능성을 확정하는 문서는 아니다.
