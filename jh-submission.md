### 2. 프로젝트 아이디어 및 계획

* **프로젝트 명/컨셉:** **AI-Assisted Serialized Web Novel Authoring Platform (웹소설 연재 코파이럿)**
* **선택 테마:** Build for Your World (직접 겪은 문제를 해결하고 새로운 가능성 열기)
* **제출 내용 (영문 요약):**
> "I want to build an AI-powered co-pilot platform tailored for serialized web novel authors. Serialized writing often suffers from consistency issues, such as plot holes, character trait drift, and managing massive world-building lore over hundreds of chapters. This tool will leverage Meta's advanced model APIs to maintain a dynamic memory of the novel's lore, assist in plotting fast-paced genre fiction chapters, and integrate image generation for character stats and key scenes to streamline the author's creative workflow."



---

### 3. 기술 역량 소개 (최근 개발한 AI 프로젝트)

* **프로젝트 명:** **speaking-kiosk** ([GitHub 저장소](https://github.com/kimiyo/speaking-kiosk))
* **제출 내용 (영문 요약):**
> "I recently developed **speaking-kiosk**, a multi-tenant voice ordering platform and reusable runtime that combines real-time speech-to-speech AI (supporting Google Vertex Gemini Live and OpenAI Realtime APIs) with verified tool calling.
> **Key Architecture & Techniques:**
> * **Real-time Voice & Tool Routing:** Implemented bidirectional live speech sessions, chunked PCM audio pipelines, barge-in/interrupt handling, and robust tool-calling contracts (handling 9 core commerce tools like cart management, product lookup, and order submission).
> * **Modular Deployment Packs:** Designed a file-pack architecture (`.kioskpack` build/install system) allowing the same Python/FastAPI/Node.js runtime to dynamically adapt its UI, prompts, and catalog data for various store domains (e.g., coffee shops, pizza restaurants).
> * **Multi-Tenant Management:** Built secure Google/PIN authentication, role-based access control (Owner/Staff/Admin), and SQLite-backed session tracking to run seamless public-device kiosk workflows."
